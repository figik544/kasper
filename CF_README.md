# Галактическая Империя - Cloudflare Workers

Cloudflare Workers версия веб-портала Федерации Галактической Империи.

## Архитектура

Проект использует:
- **Cloudflare Workers** - для запуска веб-приложения
- **Hono** - веб-фреймворк для Cloudflare Workers
- **Cloudflare D1** - для хранения данных
- **Discord Bot** - для интеграции с Discord

## Установка и развертывание

### Требования

- Node.js 18+
- npm или yarn
- Wrangler CLI (`npm install -g wrangler`)

### Установка зависимостей

```bash
npm install
```

### Локальная разработка

1. Установите переменные окружения в файле `.dev.vars`:
   ```
   BOT_TOKEN=your_discord_bot_token_here
   ADMIN_PASSWORD=2011
   ENVIRONMENT=development
   ```

2. Запустите локальный сервер:
   ```bash
   wrangler dev
   ```

Приложение будет доступно по адресу `http://localhost:8787`

### Развертывание на Cloudflare

1. Авторизуйтесь в Cloudflare:
   ```bash
   wrangler login
   ```

2. Настройте проект (если это первый деплой):
   ```bash
   wrangler init
   ```

3. Обновите `wrangler.toml` с вашими настройками:
   - `account_id` - ваш ID аккаунта Cloudflare
   - `d1_database` - настройки базы данных

4. Создайте базу данных D1:
   ```bash
   wrangler d1 create galactic_empire_db
   ```

5. Разверните приложение:
   ```bash
   wrangler deploy
   ```

## Переменные окружения

- `BOT_TOKEN` - токен Discord бота
- `ADMIN_PASSWORD` - пароль для админ-панели (по умолчанию: 2011)
- `ENVIRONMENT` - режим работы (development/production)

## Маршруты

- `/` - Главная страница
- `/features` - Страница функций бота
- `/community_plan` - План сообщества
- `/servers` - Список серверов Федерации
- `/join_federation` - Форма присоединения к Федерации
- `/admin` - Админ-панель (пароль: 2011)
- `/20111102` - Секретная админ-панель
- `/api/status` - Статус API
- `/api/federations` - API списка федераций

## Интеграция с Discord

Приложение полностью интегрировано с Discord ботом:
- Все заявки на присоединение к Федерации синхронизируются с ботом
- Управление через веб-интерфейс влияет на бота
- Статистика пользователей доступна через веб-портал

## Безопасность

- Админ-панель защищена паролем (2011)
- Секретная админ-панель доступна по скрытому пути
- Все операции привязаны к Discord ID пользователей
- Соблюдение политики авторитарности в отношении всех федеративных серверов

## Федеративная система

- Нова Сектор как главный сервер Федерации
- Возможность присоединения других серверов как федеративных республик
- Единая система управления и контроля
- Соблюдение политических соглашений между серверами
