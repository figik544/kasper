# Галактический Имперский Discord Бот

Комплексный Discord бот с тематикой Звёздных Войн, авторитарной политикой, РП-элементами, экономической системой и системой уровней.

## Особенности

### Модерация
- Обнаружение спама и автоматическое применение мута
- Система предупреждений с настраиваемыми лимитами
- Команды бан, кик и мут для администраторов
- Возможность очистки сообщений

### РП-элементы
- Система опыта (XP) для активных участников
- Прогрессия уровней с присвоением рангов
- Экономическая система с кредитами
- Ежедневные награды
- Магазин с покупаемыми предметами
- Система инвентаря
- Мини-игры (дуэли, задания)

### Тематика Звёздных Войн
- Ранговая система, вдохновлённая военной иерархией Звёздных Войн
- Роли автоматически создаются с соответствующими цветами
- Тематические каналы, организованные по категориям
- Элементы авторитарной политики, смешанные с вселенной Звёздных Войн

### Система авторитета
- Автоматическое присвоение ролей на основе уровня
- Прогрессия от Рекрута до Императора
- Специальные политические роли для административного контроля

### Управление правительством
- Команды для управления структурой правительства
- Назначение и удаление канцлеров и министров
- Смена верховного правителя
- Политико-экономическая РП зона с реальной внутренней политикой

### Система рекламы
- Настройка рекламных сообщений
- Управление частотой показа рекламы
- Включение/выключение рекламы

### Админ-панель
- Веб-интерфейс для управления ботом
- Доступ по паролю (2011)
- Управление правительством, рекламой и настройками
- Статистика пользователей и активности
- Полный контроль над системой

## Архитектура

Проект разделен на несколько модулей:
- `main.py` - основной файл запуска бота с полным функционалом управления
- `admin_panel.py` - веб-интерфейс админ-панели
- `modules/database.py` - работа с базой данных
- `modules/moderation.py` - система модерации
- `modules/economy.py` - экономическая система
- `modules/levels.py` - система уровней
- `modules/rpg.py` - РП-элементы
- `modules/star_wars.py` - тематика Звёздных Войн
- `modules/help.py` - система помощи
- `templates/` - HTML шаблоны для админ-панели

## Установка

### Требования
- Python 3.7 или выше
- Discord аккаунт и сервер с правами администратора

### Пошаговая установка

1. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

2. **Создание Discord бота**
   - Перейдите на https://discord.com/developers/applications
   - Нажмите "New Application" и дайте ему имя
   - Перейдите на вкладку "Bot" и нажмите "Add Bot"
   - Скопируйте токен бота (храните его в безопасности!)

3. **Приглашение бота на сервер**
   - Перейдите в раздел "OAuth2" → "URL Generator"
   - Выберите область "bot"
   - Выберите права, которые вы хотите предоставить (рекомендуется administrator для полной функциональности)
   - Скопируйте сгенерированный URL и откройте его в браузере

4. **Запуск бота**
   ```bash
   python main.py
   ```

5. **Запуск админ-панели**
   ```bash
   python admin_panel.py
   ```
   Админ-панель будет доступна по адресу http://localhost:5001

## Команды

### Публичные команды
- `!profile [@user]` - Просмотр профиля пользователя
- `!leaderboard` - Таблица лидеров
- `!daily` - Получить ежедневную награду
- `!balance [@user]` - Проверить баланс кредитов
- `!rankup` - Попытаться получить более высокий ранг
- `!shop` - Просмотреть имперский рынок
- `!buy [item]` - Приобрести предметы за кредиты
- `!inventory [@user]` - Просмотр инвентаря
- `!faction` - Информация о фракциях
- `!lightsaber_color` - Цвет светового меча
- `!help [module]` - Справка по командам

### Команды управления правительством (только владелец бота)
- `!set_supreme_ruler @user` - Установить верховного правителя
- `!add_chancellor @user` - Добавить канцлера
- `!remove_chancellor @user` - Удалить канцлера
- `!set_minister [ведомство] @user` - Назначить министра
- `!remove_minister [ведомство]` - Удалить министра
- `!gov_info` - Показать структуру правительства

### Команды управления рекламой (только владелец бота)
- `!enable_ads [частота_в_часах]` - Включить рекламу
- `!disable_ads` - Выключить рекламу
- `!set_ad_message [сообщение]` - Установить рекламное сообщение
- `!ad_info` - Показать информацию о рекламе

### Команды изменения правительства (владелец и канцлеры)
- `!change_government [add_chancellor|remove_chancellor|set_minister|remove_minister] [цель] [@user]` - Изменить структуру правительства

## Развертывание на Render

Для развертывания бота на Render:

1. Создайте репозиторий на GitHub
2. Добавьте все файлы проекта в репозиторий
3. Войдите в Render и создайте новую службу (Web Service)
4. Выберите GitHub репозиторий с ботом
5. В настройках службы укажите:
   - Environment: Python
   - Branch: main
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python main.py`
6. Добавьте переменные окружения:
   - DISCORD_BOT_TOKEN: ваш токен бота
   - DATABASE_URL: URL для базы данных (если используется)
7. Запустите деплой

## Cloudflare Workers API

ВАЖНО: Discord боты НЕ могут быть размещены на Cloudflare Workers из-за технических ограничений (постоянные WebSocket-соединения). 
Файл `src/index.js` предоставляет только API для управления ботом, который должен быть размещен на другом хостинге.

Для развертывания API управления на Cloudflare Workers:

1. Установите Node.js и Wrangler CLI:
   ```bash
   npm install -g wrangler
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Авторизуйтесь в Cloudflare:
   ```bash
   wrangler login
   ```

4. Разверните приложение:
   ```bash
   wrangler deploy
   ```

- `POST /api/government/set_minister` - Назначить министра
- `POST /api/government/remove_minister` - Удалить министра

- `POST /api/advertising/enable` - Включить рекламу
- `POST /api/advertising/disable` - Выключить рекламу
- `POST /api/advertising/update_message` - Обновить рекламное сообщение

#### Статистика:
- `GET /api/stats` - Получить статистику бота
