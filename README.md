# Галактический Имперский Бот

## Описание
Галактический Имперский Бот - это комплексный Discord бот с тематикой Звёздных Войн, авторитарной политикой, РП-элементами, экономической системой и системой уровней.

## Функции
- Модерация сервера (бан, кик, мут, предупреждения)
- Экономическая система (баланс, переводы, магазин, инвентарь)
- Система уровней и опыта
- RPG элементы (дуэли, задания, создание персонажей)
- Тематика Звёздных Войн (фракции, способности Силы, факты о галактике)
- Правительственная система (верховный правитель, канцлеры, министры)
- Рекламная система

## Команды
### Помощь
- `!help` - Информация о боте
- `!about` - Информация о боте

### Модерация
- `!ban <member> [reason]` - Блокировка пользователя с сервера
- `!kick <member> [reason]` - Выгоняет пользователя с сервера
- `!mute <member> [duration=10]` - Мутит пользователя на определенное время
- `!warn <member> <reason>` - Выдает предупреждение пользователю
- `!unwarn <member>` - Сбрасывает предупреждения пользователя
- `!warnings <member>` - Показывает количество предупреждений у пользователя
- `!clear <amount>` - Удаляет указанное количество сообщений

### Экономика
- `!balance [member]` - Проверка баланса кредитов
- `!daily` - Ежедневная награда
- `!transfer <member> <amount>` - Перевод кредитов другому пользователю
- `!shop` - Отображение имперского рынка
- `!buy <item_name>` - Покупка предмета из магазина
- `!inventory [member]` - Просмотр инвентаря пользователя
- `!use <item_name>` - Использование предмета из инвентаря
- `!trade <member> <item_name> [quantity=1]` - Обмен предметами с другим участником
- `!givecredits <member> <amount>` - Выдача кредитов пользователю (только для администраторов)

### Уровни
- `!profile [member]` - Показывает профиль пользователя с его статистикой
- `!leaderboard` - Показывает топ игроков по уровню
- `!rankup` - Попытка получить более высокий ранг через испытания
- `!setrank <member> <rank_name>` - Ручная установка ранга пользователю (только для администраторов)

### RPG
- `!duel <opponent>` - Вызов на дуэль другого участника
- `!quest` - Выполнение задания для получения награды
- `!char_create <char_class>` - Создание персонажа с определённым классом

### Звёздные войны
- `!faction` - Показывает информацию о фракциях в Галактике
- `!imperial_motto` - Показывает имперский лозунг
- `!imperial_hierarchy` - Показывает имперскую иерархию
- `!lightsaber_color` - Определение цвета светового меча по типу персонажа
- `!force_ability` - Показывает случайную способность Силы
- `!galactic_fact` - Показывает интересный факт о галактике
- `!battle_simulator <faction1> <faction2>` - Симуляция битвы между двумя фракциями

### Правительство
- `!set_supreme_ruler <user>` - Установить верховного правителя (только для владельца бота)
- `!add_chancellor <user>` - Добавить канцлера в правительство
- `!remove_chancellor <user>` - Удалить канцлера из правительства
- `!set_minister <ministry> <user>` - Назначить министра в ведомство
- `!remove_minister <ministry>` - Удалить министра из ведомства
- `!gov_info` - Показать структуру правительства
- `!change_government <action> [target] [user]` - Команда для изменения структуры правительства

### Реклама
- `!enable_ads [frequency_hours=6]` - Включить рекламу с заданной частотой
- `!disable_ads` - Выключить рекламу
- `!set_ad_message <message>` - Установить рекламное сообщение
- `!ad_info` - Показать информацию о рекламе

### Другое
- `!setup_imperial_server` - Настройка сервера в стиле Империи

## Установка
1. Установите Python 3.9 или выше
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте config.json с вашим токеном бота
4. Запустите бота: `python main.py`
